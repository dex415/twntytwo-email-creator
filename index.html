Getting this into Shopify Email

    
    
      
  1. Shopify admin → Messaging → Create message → Email.
    2. 
      
  2. Keep Shopify's logo band and its footer. This app only generates the middle — campaign tag down to the 4-button footer.
    3. 
      
  3. In the left Email colors panel set Content background to #000000 and Border to #000000. Without this the campaign shell stays white and frames the dark card.
    4. 
      
  4. Delete the default image and button sections.
    5. 
      
  5. Add section → scroll to Custom → Custom Liquid.
    6. 
      
  6. Hit Copy Liquid here, paste into that section.
    7. 
      
  7. Set Subject and Preview text from the fields in the middle column — Custom Liquid cannot set those.
    8. 
      
  8. Send test to yourself before scheduling.
    9. 
    

    
Shopify always appends its own footer (social icons, Bronx address, unsubscribe, copyright) below your content. That is required and can't be removed, so the Footer Grid block is optional — use it when you want the Customer Service / Subscribe buttons, skip it to keep the email short.

    
Prefer Shopify's native Countdown section over the Launch Date block if you want a live timer — add it as a separate section above your Custom Liquid.

    
Product images look like different sizes? Each product has a Size slider — but it only shrinks. Email clients don't support the CSS needed to zoom in, so shrink the item shot too close until it matches the one beside it, rather than trying to enlarge the far one. For a real tighter crop, append &width=800&height=800&crop=center to a Shopify CDN image URL.
